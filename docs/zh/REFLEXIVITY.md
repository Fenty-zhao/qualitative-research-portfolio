# 研究者反思：访谈决策、信任关系与研究预设

[← 研究案例（英文）](../../projects/living-away-from-home/README.md) · [编码证据（英文）](../../projects/living-away-from-home/coding-to-themes.md) · [方法与伦理（英文）](../../projects/living-away-from-home/methods-and-ethics.md)

本文在最终提交的质性研究方法课程论文的自我评价部分基础上，结合访谈逐字稿与研究草稿，对当时的研究过程作进一步反思。

## 1. 共同的文化背景，不同的生活经历

我采访的是一位通过课程认识的中国硕士生。我们使用同一种语言，熟悉部分相同的文化参照，也都有在英国求学的经历。这些共同点让访谈更容易展开，对话也更加自然。

但共同背景并不意味着我们此前的教育经历相同。我成长于中国的一座小城市，在这样的环境中，初高中寄宿、之后离开家乡去其他城市接受高等教育，是熟悉且往往被预期的求学路径。这影响了我最初设计的访谈提纲：我预期受访者在来英国之前已有离家生活的经历，因此准备了一些比较她在中国与英国生活经验的问题。

访谈过程中，我了解到她此前一直在家乡所在的城市上学，来英国前并未真正离家生活。原本的比较路径因而不适用于她。我没有继续沿着这个无法反映她实际经历的方向提问，而是将讨论调整为她第一次独立生活的体验。

这并不是因为我没有提前收集一份完整的个人履历。探索性访谈本就包含在对话中逐渐了解受访者的过程。这里的方法启示在于：当我发现访谈提纲中隐含的预设不符合受访者的叙述时，需要识别这一点，并相应调整方向。

## 2. 遵循提纲，同时给受访者充分解释的空间

半结构式访谈提纲帮助我将对话保持在研究问题的范围内。但重新查看逐字稿时，我也发现自己有时会在受访者尚未讲完一个抽象想法时打断她。当时，我在考虑剩余的问题，以及如何让访谈继续向前推进。

其中一个例子涉及她如何理解「离家」。打断她之后，我又回到这个话题，询问她能否继续解释刚才尚未说完的内容。随后，她进一步区分了作为具体物理行为的「离家」，与其他人可能赋予这一行为的、更重大的情感意义。

这一段交流既反映了我在倾听方面的不足，也记录了我在访谈过程中尝试修复打断的行为。如果以后再开展访谈，我会更好地利用停顿，在给出自己的概括之前，让受访者充分表达一个想法。

## 3. 信任关系也是一种研究资源

我与受访者本来就认识，也共享一些中国文化参照，这为讨论提供了熟悉的起点。我们能够谈论家庭期待、日常生活安排以及网络表达，而不必从头解释每一个文化背景。受访者也谈到了个人的沮丧、实际困难，以及她不认同的观点。

这种熟悉感有助于营造轻松的交流氛围。不过，对话舒适并不自动证明研究解释一定正确。理解一个共同的文化参照，与理解这个参照对受访者个人意味着什么，仍然是两回事。因此，访谈仍需要澄清问题，并认真关注她实际说了什么。

## 4. 解释也是访谈互动的一部分

访谈中，我提出过一种可能性：受访者务实地应对困难的方式，是否与更广泛的东亚文化期待有关。她并没有简单地赞同这一解释，而是反过来质疑了这种概括。随后，对话进一步涉及人与人之间的差异，以及群体刻板印象如何形成。

我并不认为这段交流是一个严重错误，或研究设计突然改变的时刻。在半结构式访谈中，研究者提出一种可能的解释，而受访者对其加以限定或修正，本就可以是正常的互动过程。这段交流的价值在于，受访者能够用自己的方式作出回应，并让对话超出我最初提出的解释框架。

重新审视访谈材料，也让我进一步意识到：研究者自己的解释与受访者的叙述，应当加以区分。

## 5. 研究局限与未来改进

本项目基于一场访谈，没有结合额外的观察或日记资料。因此，它能够深入理解一名受访者的经历，却不能据此描述整个国际硕士生群体。对于受访者日常生活环境的了解如果更加充分，也可能帮助读者判断这些发现与其他情境有多大关联。

如果继续开展研究，我会招募成长地区及教育经历更加多样的参与者，保留更完整、带日期的编码记录，并在研究问题需要时考虑补充其他资料来源。

## 6. 从学术访谈到决策导向的用户研究

这项研究让我获得了访谈设计、数据收集、主题分析和研究者反思的实践经验。同时，它也促使我思考：在产品研究环境中，这些方法需要如何调整。

**从决策开始，而不是从访谈开始。** 在学术研究中，研究问题提供了研究的起点。而在产品团队中，我会首先明确业务问题、研究需要支持的决策，以及现有数据或相关团队成员的观点已经提供了哪些信息。这有助于界定研究范围，并判断访谈、观察、可用性测试、问卷，或多种方法的组合，哪一种更适合当前问题。

**根据相关经历招募参与者。** 我的课程研究采访了一位符合研究条件、且方便参与的同学。在产品研究中，我会围绕与研究问题相关的用户行为和经历制定招募标准，同时考虑哪些用户群体可能提供不同的视角。筛选的目的是确认参与条件，而不是提前预测参与者会说些什么。

**在探索与研究优先事项之间取得平衡。** 半结构式访谈不仅是按照提纲提问，也不是每当出现意料之外的话题就继续追加问题。我会判断新信息是否有助于回答研究问题、是否挑战了重要假设，以及它值得占用多少访谈时间。对于相关的发现，可以进一步探索；其他观察则可以记录下来，留待后续研究，而不使当前访谈偏离方向。

**将研究发现与实际行动联系起来。** 我的课程研究通过三个主题解释了一名受访者的经历。而在产品研究中，我还会考虑不同参与者的发现如何比较、哪些证据支持每项解释，以及这些发现能够为哪些产品决策提供信息。当访谈本身不足以支持判断时，可以借助行为数据或后续测试进一步评估，再决定是否优先实施相关改动。

这项课程研究能够迁移的价值，来自我实际开展过的研究活动。下一步则是在真实决策过程中应用这些方法，同时考虑用户需求、研究证据、业务优先级和实际资源限制。
